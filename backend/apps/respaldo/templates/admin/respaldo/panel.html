Backup completo

Genera un único archivo .zip con:

  • Todo el código (backend, frontend y scripts), media/ y los archivos privados (fotos de medidores, comprobantes).
  • La base de datos (copia consistente de SQLite, o pg_dump si está en PostgreSQL).
  • Un manifiesto.json con la fecha, el motor y advertencias.

Se excluyen siempre venv/, node_modules/, __pycache__/, dist/, .vite/, staticfiles/ y cualquier rastro del repositorio (.git/, .github/, .gitignore, .gitattributes, .gitmodules).

⚠ El archivo contiene los datos de todas las instituciones y el archivo .env. Guárdelo en un lugar seguro.

💡 Si el sistema está en PostgreSQL y quiere llevar los datos a otra PC sin restaurar un volcado SQL, use antes Migración de base de datos → Traer datos a SQLite.

Restaurar

Se hace desde la consola del servidor (detiene el sistema, verifica el archivo, guarda un respaldo de lo actual y vuelve a arrancar):

Windows:          start.bat verificar  ruta\del\respaldo.zip
                  start.bat restaurar  ruta\del\respaldo.zip
Linux:            ./start.sh restaurar /ruta/del/respaldo.zip
Servidor (root):  bash scripts/servidor/restaurar.sh /ruta/del/respaldo.zip
